# RAS Commander MCP

This server supplies bounded, read-only HEC-RAS text information to informational
subagents. See [tools](tools.md), [installation](installation.md),
[architecture](architecture.md), and [migration](migration.md).

Use the [full RAS Commander library](https://rascommander.info/ras/) for execution,
modification, binary results, GIS and larger analyses. This project is independent
of USACE HEC and does not imply HEC endorsement.
